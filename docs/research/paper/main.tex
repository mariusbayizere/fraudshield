\textbf{How to read the numbers.} Every figure is measured on the FraudShield-EAC synthetic
benchmark; none describes a real institution, customer or regulator. Every number comes from the
repository and is checked against its evidence file at a named git reference, the tag
\texttt{m4-complete} (commit \texttt{72e7790}) unless Appendix~\ref{app:evidence} names another; the source of each is listed in \texttt{numbers.tex} and the check in
\texttt{number\_audit.md}. The specification's acceptance thresholds, for the model and for the
service, are called \emph{gates}; gate ranking metrics are reported as margins over the best single feature on the same
rows, not over chance. A statement that rests on inference rather than
measurement says so in the sentence. Intervals are \nIntervalLevel{} unless stated otherwise. \textbf{Fraud on this benchmark arrives as
multi-row incidents on one account, so test rows are not independent}: intervals marked
account-clustered resample whole accounts, and the alert budgets' precision intervals resample
days; every other interval treats rows as independent and is
narrower than it should be by an amount not measured (Sections~\ref{sec:method}
and~\ref{sec:limitations}). Results a
later milestone will produce are marked \emph{deferred}, with the milestone; no value is
estimated in their place.}}
