\appendix
\section{Identifiers used in this paper}
\label{app:identifiers}

Every identifier below is defined in the repository at \texttt{m4-complete}, except ADR~0034, ADR~0035,
ADR~0055, ADR~0058, ADR~0059, PB-72 and PB-76, which are defined on the main branch after it (as are ADR 0031's amendment and
PB-67's conclusion); C-8's refutation and ADR 0028's correction are on this paper's branch only, and ADR 0084 and PB-132, which were written for the analyst console and are
copied into this release from the console's separate, unmerged branch. The console itself is not part
of this paper's release and is not evaluated. Resolutions D-xx are the
binding corrections to the specification (\texttt{docs/srs/defect\_register.md}); ADRs are architecture
decision records (\texttt{docs/adr/}); C-n are claims in \texttt{docs/research/claims\_register.md}; PB-n
are backlog items (\texttt{docs/backlog/product.md}).
