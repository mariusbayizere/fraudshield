\section{Feature catalogue}
\label{app:features}

The \nFeatures{} features of the registry at \texttt{m4-complete}, by group (the registry is
\texttt{ml/src/\allowbreak fraudshield\_ml/\allowbreak features/\allowbreak registry.py}), each with the first sentence of its definition exactly as the registry
words it. Where the registry says ``confirmed fraud'' it means fraud by the observed label, not the
``Confirmed'' of Table~\ref{tab:reconcile}. The table is generated from the registry by \texttt{appendix\_features.py}, which also
checks it, so every window, threshold and constant below is a quotation of the code at that tag
rather than a number typed into this paper; the registry holds the full definitions. The models
train on \nTrainableFeatures{}: the features marked below are the \nNoSourceFeatures{} with no source
data on this benchmark (ADR 0055) and the one that is constant. \texttt{round\_sum\_flag} is trained,
but its denominations are assumed (Section~\ref{sec:limitations}). The synthetic-identity composite is
described as it runs on this benchmark in Section~\ref{sec:features}.
