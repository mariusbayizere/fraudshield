\section{Measurements deferred or not yet done}
\label{app:deferred}

The items below are not measured here, and each row says what it waits for rather than only which
milestone it belongs to. The performance figures need, among other things, a dedicated benchmark
machine, because ADR 0010 admits performance gate figures only from one whose specification is
recorded when it is used. The verification campaign (milestone M10) specifies that machine
(\url{https://github.com/mariusbayizere/fraudshield/blob/15a5ad6/docs/benchmarks/m10_machine_spec.md}),
none has been provisioned, and whether and how to provision it is an open decision of the project's
owner; the campaign also waits for the system's milestones to be merged. The shadow-mode AUC
difference is not a hardware question; it needs a deployment running the shadow comparator for its
full window, which does not exist. The run at the specification's scale needs no dedicated machine
and has not been made. The last items belong to this milestone (M11) and are not yet done. The text
marks each performance figure that waits for the machine as \emph{deferred}, and says where each
other item is not measured. The measurements
the specification asks of the model evaluation itself, including full-volume training, alert
budgets, results by month, a cost curve and a partial fairness report, are reported in
Sections~\ref{sec:evaluation} and~\ref{sec:ethics}; the one not measured, the value of Isolation
Forest routing for novelty, is listed there. No value is estimated in place of any of them.
