\section{Evidence index}
\label{app:evidence}

Every file a number in this paper is read from, the git reference it is read at, the evidence stamp
the file carries where it has one, and how many values are read from it; a file the text cites but no number is read from shows none. The table is written by
\texttt{audit\_numbers.py} from the sources it actually read, so it cannot list a file the audit did
not check or omit one it did. Files are read at the tag \texttt{m4-complete} unless the reference says
otherwise: the learning curve, the lab notebook's later entries, ADR 0034, ADR 0055, PB-66's benchmark files,
its pre-specification and the test-set access log, and the files this paper produced postdate the tag and are read at the commit or tag named. A file without a stamp, such as the
single-feature measurement, records no producing commit of its own. The value-by-value map is
\texttt{number\_audit.md}; the feature definitions of Appendix~\ref{app:features} are read from the
registry by \texttt{appendix\_features.py}.
