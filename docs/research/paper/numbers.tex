% The claims register gate (docs/research/claims_register.md) applies to every entry: a number
% is MEASURED (commit and run given) or SOURCED (checkable citation given); nothing else may be
% stated. Sections use these macros and never type a result directly; check_numbers.py enforces
% that.
%
%   \meas{x}      MEASURED: a result or a count, from an evidence file or quoted from a document.
%                 Printed as is.
%   \prov{x}      MEASURED on a milestone not yet tagged complete. Printed with a dagger. None is
%                 in use: every M4 value was re-verified at m4-complete (72e7790) on 2026-09-22 by
%                 audit_numbers.py and moved to \meas.
%   \srcd{x}      A value fixed by a document, not a result: a specification threshold, target or
%                 count of the specification's own items, or a prediction or range recorded as made
%                 in advance (whether that order is established is stated in the text, not here),
%                 including each component of a rule fixed in advance, an assumed value a
%                 pre-specification fixes (the alert budgets) and a document's own definition of a
%                 term. Any other count or measurement quoted from a document is \meas, and so is a
%                 constant read from the code or its configuration. The class is not checked by
%                 audit_numbers.py and both print the same.
%   \notyet{Mx}   A result a later milestone produces. Printed in italics as "not yet measured (Mx)".
%

%   6abde44e  1,006,249 rows (claims register header; M3 and the first M4 battery)

%             non-burst variant pre-specified in repository history; the M4 gate and the E1-corrected battery)
% Evidence files are read at the m4-complete tag (72e7790), which is on main; each file begins
% with its own evidence-commit and evidence-tree-state stamp.
